# Sebanks Co skills

This repository is the version-controlled source for Sebanks Co custom Codex skills used in SCOS development and local coding workflows.

## Skill catalog

- `build-scos-expandable-tables` - canonical SCOS parent/child table behavior and UI contract.
- `code-review-and-quality` - multi-axis code review before integration.
- `coding-guardrails` - general implementation safeguards.
- `create-default-sheet-readme-format` - standard Google Sheets instruction-tab formatting.
- `maintain-code-index` - repository code-index maintenance.
- `oni-apps-script-guardrails` - safe Google Apps Script and `clasp` operations.
- `oniseb-reliable-coding` - source-of-truth, server-authority, schema, Git, deployment, and UI rules.
- `scos-change-order-package` - controlled SCOS change-order package workflow.
- `scos-financial-forecast` - controlled project and portfolio financial forecasting.
- `scos-subcontract-award-pay-app` - subcontract award and pay-application workflow.

Each directory under `codex-skills/` is a complete skill package. Keep its `SKILL.md`, `agents/`, `references/`, `scripts/`, and `assets/` together when installing or updating the skill locally.

System-bundled and unrelated third-party skills are intentionally excluded.
