# Index Structure Reference

Use this structure when creating or heavily refreshing an index.

## Suggested Sections

1. Title and last updated timestamp
2. Source locations
3. GitHub / source control
4. Project sections
5. Push boundaries
6. Sync notes
7. Security notes

## Project Section Template

```markdown
## Project Name

- Purpose:
- Canonical local folder:
- Synced copy:
- GitHub repo:
- Apps Script ID:
- Spreadsheet or document ID:
- Main files:
- README / docs:
- Last verified:

### Push Boundary

- Include:
- Exclude:
```

## Status Language

Use factual language:

- `Verified by clasp status on <date/time>`
- `Pushed <n> files at <time>`
- `Draft PR opened: <url>`
- `Working tree dirty; inspect before staging`
- `Temporary inspection folder; do not push`

Avoid vague language:

- `probably deployed`
- `looks synced`
- `should be fine`
